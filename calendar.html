Subscribing by hand
  1. Outlook on the web or the new Outlook app: open Calendar → Add calendar → Subscribe from web → paste the link above → name it “MECH420” → Import.
  2. Classic Outlook for Windows: Calendar → Add Calendar → From Internet… → paste the link.
  3. iPhone: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the link.
  4. Google Calendar: Other calendars → + → From URL → paste the link.
Outlook checks for updates every few hours, so a change made today may take a while to appear. This page always shows the current dates.
